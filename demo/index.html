Eight projects had already converged. This is the extraction.

Weft and Vantage were shipping byte-identical glass values, radii, motion and theme triad without sharing a stylesheet. Zeno had independently built a colour law where every value carries its measured contrast ratio and a script fails the build if it drifts. So: one grammar, eight themes, and a budget that runs on all sixteen palettes in CI — and, on this page, on whichever one you are looking at right now.

Clone and verify
git clone https://github.com/abheet19/glass.git
node glass/scripts/contrast.mjs      # prove it before you trust it
Git submodule
git submodule add https://github.com/abheet19/glass.git vendor/glass
Plain CSS import
<link rel="stylesheet" href="src/tokens.css">
<link rel="stylesheet" href="src/themes/weft.css">
<link rel="stylesheet" href="src/primitives.css">

<html data-glass="weft">            # hue
<html data-glass="weft" data-theme="light">
<html data-glass="weft" data-flat="1">  # no blur
Verify
node scripts/contrast.mjs --verbose    # every pair
node scripts/contrast.mjs --theme weft # one theme
node scripts/contrast.mjs --emit-json  # rebuild tokens.json
