GLASS zeno · dark

a personal design system

Eight projects had already
converged. This is the extraction.

Weft and Vantage were shipping byte-identical glass values, radii, motion and theme triad without sharing a stylesheet. Zeno had independently built a colour law where every value carries its measured contrast ratio and a script fails the build if it drifts. Five side projects were saying the same three things in a vocabulary I had improvised. So: one grammar, eight themes, and a budget that runs on all sixteen palettes in CI.

01 — the ramp

A theme owns hue. The system owns everything else.

Every swatch below is read live out of getComputedStyle and measured in this page, right now, against the plane it is allowed to sit on. Switch theme or ground in the bar and the numbers recompute. The lightness of each step is identical in all eight themes — only the hue rotates.

02 — the law

Machine-verified, not asserted

The same pairs scripts/contrast.mjs asserts in CI, computed here in the browser from the live tokens. plane is --raised, the lightest opaque surface text may land on; glass is --gl-worst, the worst realistic composite behind a pane. If a row ever reads FAIL, the build is already red.

03 — primitives

Seven, and no more

.glass .card .btn .field .chip .state .gauge — every one of them drawn entirely from tokens. The a11y fallbacks are live: press Reduce transparency in the bar and every pane on this page drops its blur for the opaque --raised plane, which is a surface the budget already measures.

.glass · .glass-inner

The material

A tint, a real blur with a saturation lift, a 1px edge that makes the pane an object, and the specular line that says which way the light is.

.state · .chip

Four channels, of which colour is one

A fill, a key bar, a glyph and a word. Print this in greyscale and the status still reads — the four fills are held apart in luminance, and the script fails if any two collapse.

.gauge

A quantity, and only when it is known

There is no indeterminate spinner in this package. A spinner is an animation that claims to be information; if the progress is not known, say so in words.

05 — the eight

One grammar, eight hues

Each theme file is nine numbers: the ground's hue and chroma, and the hue plus a per-ground chroma for each accent. No structural token is in scope inside a theme, so a theme cannot break the ladder. The strips below are resolved live from those nine numbers. Click a row to wear it.

06 — how to use it

Three CSS files and an attribute

plain css

<link rel="stylesheet" href="src/tokens.css">
<link rel="stylesheet" href="src/themes/weft.css">
<link rel="stylesheet" href="src/primitives.css">

<html data-glass="weft">            <!-- hue -->
<html data-glass="weft" data-theme="light">
<html data-glass="weft" data-flat="1">  <!-- no blur -->
